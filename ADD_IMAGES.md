# How to Add Images

You have several options to add images:

## Option 1: Drag and Drop in Cursor
1. Drag your image files directly into this Cursor window
2. I'll save them to the right location

## Option 2: Terminal Copy
1. Put your images in ~/Downloads or Desktop
2. Run:
   ```bash
   cd ~/portfolio-website/images
   
   # For LLNL images
   cp ~/Downloads/clamp-model.jpg llnl/
   cp ~/Downloads/rtv-injection.jpg llnl/
   
   # For Space Mission images  
   cp ~/Downloads/satellite-frame.jpg space-mission/
   cp ~/Downloads/satellite-assembly.jpg space-mission/
   cp ~/Downloads/modal-analysis.jpg space-mission/
   
   # For Yerf-Dog images
   cp ~/Downloads/yerf-before.jpg yerf-dog/
   cp ~/Downloads/yerf-after-1.jpg yerf-dog/
   cp ~/Downloads/yerf-after-2.jpg yerf-dog/
   ```

## Option 3: Send Me the Actual Image Files
Paste them in the chat and I'll save them

Once images are added, I'll update the HTML files to display them!
